# Ô Việc

Bảng quản lý công việc: một trang, tám ô. Tick việc thì dòng rớt xuống **Đã xong**. Có thể thêm/bớt ô, đổi tên ô. Dữ liệu lưu trên trình duyệt.

## Dùng

- Gõ vào **Thêm việc…** rồi Enter
- Tick checkbox để hoàn thành
- **Thêm ô** / nút X trên ô để thêm hoặc xóa stack
- Bấm tên ô để đổi tên

## Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:8080

Stack: React 19, TanStack Start, Tailwind v4, Zustand.
